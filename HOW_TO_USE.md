# How to Use "Learn with DeepMind" - Complete Guide

## 🚀 First Time Setup (5 Minutes)

### Step 1: Get Your API Key (2 minutes)

1. **Open Google AI Studio**: https://makersuite.google.com/app/apikey
2. **Sign in** with your Google account
3. **Click** "Create API Key" button
4. **Copy** the generated key (looks like: `AIzaSyD...`)
5. **Keep it safe** - you'll need it in the next step

### Step 2: Configure the Extension (3 minutes)

1. **Open Settings**:
   - Click the extension icon in your browser toolbar
   - Click the "⚙ Settings" button at the bottom

2. **Enter Your API Key**:
   - Paste your Gemini API key in the first box
   - Click the eye icon (👁️) to verify it's correct
   - (Optional) Add Imagen API key if you have one

3. **Choose Your Preferences**:
   - **Content Complexity**: Select "Moderate" (recommended for most users)
   - **Visualization Density**: Leave at 5 (default)
   - **Language**: Select your preferred language

4. **Save**:
   - Click the big green **"💾 Save Settings"** button
   - Wait for the success message: "✅ Settings saved successfully!"
   - If you see "Settings saved & API key verified!" - perfect!

### Step 3: You're Ready! 🎉

## 📚 How to Learn with DeepMind

### Method 1: Analyze Any Web Page (Most Common)

**Use this for**: Articles, blog posts, documentation, Wikipedia, tutorials

1. **Navigate** to any learning resource (e.g., Wikipedia article)
2. **Look** for the floating button in the bottom-right corner (circle with "AI")
3. **Click** the floating button
4. **Wait** 5-10 seconds while content is extracted
5. **Side panel opens** - you're ready to learn!

**Example**: Try it on https://en.wikipedia.org/wiki/Artificial_intelligence

### Method 2: Upload a Document

**Use this for**: PDF files, text documents, study materials

1. **Click** the extension icon in your toolbar
2. **Click** "Upload Document" card
3. **Select** a .txt file from your computer (PDF support coming soon)
4. **Wait** for upload to complete
5. **Side panel opens** - ready to process!

### Method 3: From Extension Popup

**Use this for**: Quick access from any page

1. **Click** the extension icon
2. **Click** "Analyze This Page"
3. Side panel opens with current page content

## 🎯 Processing Your Learning Material

Once the side panel is open, you'll see 4 tabs. Here's what each does:

### Tab 1: 📋 PROCESS (Main Processing)

This is where the AI magic happens!

#### **Summarize Content**
- **What it does**: Creates a concise summary of the entire content
- **When to use**: When you want quick key points
- **Click**: "📋 Summarize Content" button
- **Wait**: 10-30 seconds
- **Result**: Structured summary with main ideas

#### **Extract Key Concepts**
- **What it does**: Identifies main topics and relationships
- **When to use**: Before creating mind maps or studying
- **Click**: "💡 Extract Key Concepts" button
- **Wait**: 15-40 seconds
- **Result**: Hierarchical list of concepts

#### **Simplify Language**
- **What it does**: Rewrites in easier-to-understand language
- **When to use**: When content is too technical
- **Click**: "🔍 Simplify Language" button
- **Wait**: 10-25 seconds
- **Result**: Clearer, simpler explanation

#### **Identify Patterns**
- **What it does**: Finds learning frameworks and mental models
- **When to use**: For deep understanding and retention
- **Click**: "🧩 Identify Patterns" button
- **Wait**: 20-45 seconds
- **Result**: Patterns and frameworks to remember

#### **Find Related Materials**
- **What it does**: Suggests related topics to explore
- **When to use**: When you want comprehensive learning
- **Click**: "🌐 Find Related Materials" button
- **Wait**: 15-30 seconds
- **Result**: List of related concepts to search for

### Tab 2: 🗺️ VISUALIZE (Create Mind Maps)

Turn concepts into visual diagrams!

1. **First**: Process content or extract concepts in the Process tab
2. **Switch** to "Visualize" tab
3. **Choose** visualization type:
   - **Mind Map**: Hierarchical concept visualization (default)
   - **Flow Diagram**: Coming soon
   - **Infographic**: Requires Imagen API key
4. **Click**: "🎨 Generate Visualization" button
5. **Wait**: 5-15 seconds
6. **View** your mind map!
7. **Export**: Click "💾 Export" to save as SVG file

### Tab 3: 📝 QUIZ (Test Yourself)

Generate practice questions!

1. **Switch** to "Quiz" tab
2. **Click**: "🎯 Generate Quiz" button
3. **Wait**: 15-35 seconds
4. **Review** AI-generated questions
5. **Study**: Use questions for self-testing

*(Note: Interactive quiz UI coming in next version)*

### Tab 4: 📚 LIBRARY (Saved Materials)

Access everything you've processed!

1. **Switch** to "Library" tab
2. **Browse** all saved summaries, concepts, and quizzes
3. **Filter** by type:
   - All items
   - Summaries only
   - Mind Maps only
   - Quizzes only
4. **Click** any item to view details

## 🔧 Troubleshooting

### "API Key Not Configured" Error
**Solution**:
1. Go to Settings (click extension icon → ⚙️ Settings)
2. Enter your Gemini API key
3. Click "Save Settings"
4. Wait for success message

### "Could Not Extract Content" Error
**Solution**:
1. Refresh the page
2. Try clicking the floating button again
3. If still failing, try uploading the content as a document instead
4. Some pages block content extraction - try a different source

### Floating Button Not Visible
**Solution**:
1. Refresh the page after installing extension
2. Look in the bottom-right corner
3. If still not visible, use extension icon → "Analyze This Page"

### Nothing Happens When Processing
**Solution**:
1. Check browser console (F12) for errors
2. Verify API key is entered correctly in Settings
3. Check internet connection
4. Wait longer (some processing takes 30-60 seconds)
5. Try with simpler/shorter content first

### "Settings Not Saving"
**Solution**:
1. Check browser console (F12 → Console tab)
2. Make sure API key is entered (required field)
3. Try refreshing the settings page
4. Reload the extension: chrome://extensions/ → Click reload button
5. If you see a success message but API key fails verification, double-check the key

### Clear Library
1. Go to Settings
2. Scroll to "Data Management"
3. Click "🗑️ Clear Library"
4. Confirm (warning: cannot be undone!)
5. All saved content will be deleted

## ❓ FAQ

**Q: Is it really free?**
A: Yes! The Gemini API has a generous free tier.

**Q: How many requests can I make?**
A: 60 per minute on the free tier - more than enough for learning.

**Q: Does it work offline?**
A: No, it requires internet for API calls.

**Q: Can I use it on any website?**
A: Most websites work, but some block content extraction.

**Q: Is my data private?**
A: Yes! Content is only sent to Google's APIs for processing. We don't collect or store anything.

**Q: Can I customize the processing?**
A: Yes! Adjust complexity, visualization density, and language in Settings.
