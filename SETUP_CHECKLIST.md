# Setup Checklist - AI Learning Accelerator

Use this checklist to get your extension up and running!

## ⬜ Pre-Installation

### 1. Get Your Gemini API Key
- [ ] Visit https://makersuite.google.com/app/apikey
- [ ] Sign in with Google account
- [ ] Click "Create API Key"
- [ ] Copy the API key
- [ ] Save it somewhere safe (you'll need it in a moment)

### 2. (Optional) Get Imagen API Key
- [ ] Visit https://cloud.google.com/vertex-ai
- [ ] Set up Google Cloud account
- [ ] Enable Vertex AI API
- [ ] Create Imagen API credentials
- [ ] Save the API key

### 3. Prepare Extension Icons (Choose One Option)

**Option A: Create Custom Icons (Recommended)**
- [ ] Design 16x16px icon
- [ ] Design 32x32px icon
- [ ] Design 48x48px icon
- [ ] Design 128x128px icon
- [ ] Save all as PNG with transparent background
- [ ] Place in `/assets/icons/` folder
- [ ] Use vintage/academic style matching the extension

**Option B: Use Placeholder Icons (Quick Start)**
- [ ] Visit https://favicon.io/ or similar
- [ ] Create simple "AI" text icons in brown/gold colors
- [ ] Download in all required sizes
- [ ] Place in `/assets/icons/` folder

**Option C: Use Free Icons (Fastest)**
- [ ] Find suitable icons on Flaticon.com or Icons8.com
- [ ] Download in required sizes
- [ ] Ensure license allows use
- [ ] Place in `/assets/icons/` folder

## ⬜ Installation

### 4. Load Extension in Browser
- [ ] Open Chrome or Edge
- [ ] Navigate to `chrome://extensions/` (or `edge://extensions/`)
- [ ] Enable "Developer mode" toggle (top-right)
- [ ] Click "Load unpacked" button
- [ ] Navigate to this folder (`learnfasterwithai`)
- [ ] Click "Select Folder"
- [ ] Verify extension appears in list
- [ ] Check that it shows "Enabled"

### 5. Verify Installation
- [ ] Extension icon visible in browser toolbar
- [ ] No errors shown on extensions page
- [ ] Extension ID assigned
- [ ] Can click extension icon and see popup

## ⬜ Configuration

### 6. Open Settings
- [ ] Click the extension icon in toolbar
- [ ] Click "⚙ Settings" button
- [ ] Settings page opens in new tab

### 7. Configure API Keys
- [ ] Paste Gemini API key in first field
- [ ] (Optional) Paste Imagen API key in second field
- [ ] Click eye icon to verify keys are correct
- [ ] No extra spaces before/after keys

### 8. Set Preferences
- [ ] Choose content complexity level (suggest: Moderate)
- [ ] Adjust visualization density (suggest: 5)
- [ ] Select preferred language
- [ ] Review all settings

### 9. Save Configuration
- [ ] Click "💾 Save Settings" button
- [ ] Wait for success message
- [ ] Extension will test API key automatically
- [ ] Verify "Settings saved & API key verified!" message

## ⬜ First Test

### 10. Test Content Extraction
- [ ] Open a new tab
- [ ] Navigate to any article (try Wikipedia)
- [ ] Look for floating button (bottom-right corner)
- [ ] Click the floating button
- [ ] Side panel opens
- [ ] Content info shows (word count, reading time)

### 11. Test AI Processing
- [ ] Click "📋 Summarize Content" button
- [ ] Wait for loading overlay
- [ ] Summary appears in result box
- [ ] No error messages
- [ ] Summary makes sense

### 12. Test Visualization
- [ ] Click "Visualize" tab
- [ ] Click "🎨 Generate Visualization"
- [ ] Mind map appears
- [ ] Contains relevant concepts
- [ ] Visual looks correct

### 13. Test Library
- [ ] Click "Library" tab
- [ ] See saved summary from step 11
- [ ] Item shows correct date
- [ ] Can filter items
- [ ] Library not empty

### 14. Verify Statistics
- [ ] Open Settings again
- [ ] Scroll to "Data Management"
- [ ] "Materials Processed" shows at least 1
- [ ] Other stats may show values
- [ ] Numbers look correct
