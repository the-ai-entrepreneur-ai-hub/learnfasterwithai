# Simple Start Guide - 3 Minutes to Learning!

## ⚡ Super Quick Start

### 1️⃣ Get API Key (1 minute)
```
1. Go to: https://makersuite.google.com/app/apikey
2. Sign in with Google
3. Click "Create API Key"
4. Copy it (looks like: AIzaSyD...)
```

### 2️⃣ Save Your Key (1 minute)
```
1. Click extension icon in toolbar
2. Click "⚙ Settings" button
3. Paste API key in first box
4. Click big green "💾 Save Settings" button
5. Wait for "✅ Settings saved successfully!"
```

### 3️⃣ Start Learning! (1 minute)
```
1. Open any Wikipedia article
2. Click the floating button (bottom-right corner, has "AI")
3. Click "📋 Summarize Content"
4. Wait 20 seconds
5. Read your summary!
```

## 🎯 That's It! You're Learning Faster Now!

### What You Can Do:

**📋 Process Tab** (Where you start):
- Click "Summarize Content" → Get quick overview
- Click "Extract Key Concepts" → See main ideas
- Click "Simplify Language" → Easier explanations
- Click "Identify Patterns" → Learn frameworks
- Click "Find Related Materials" → Discover more

**🗺️ Visualize Tab** (Make it visual):
- Click "Generate Visualization" → Create mind map
- Click "Export" → Save your mind map

**📝 Quiz Tab** (Test yourself):
- Click "Generate Quiz" → Get practice questions
- Review and study!

**📚 Library Tab** (Your saved stuff):
- Browse everything you've processed
- Filter by type
- Review before exams

## 🚨 Troubleshooting

### Save Button Does Nothing?
**Open browser console to see what's happening:**
1. Press **F12** on your keyboard
2. Click **"Console"** tab
3. Try clicking "Save Settings" again
4. Look for red error messages
5. Send me the errors!

**Common issues:**
- ❌ No API key entered → Enter your key first!
- ❌ Extension not reloaded → Go to chrome://extensions/ and click reload
- ❌ Console shows errors → Copy the error message

### Can't See Floating Button?
1. Refresh the page (F5)
2. Look in bottom-right corner
3. Still not there? Click extension icon → "Analyze This Page"

### Nothing Happens When I Click Process?
1. Wait longer (can take 30-60 seconds)
2. Check you entered API key in Settings
3. Try on a simple Wikipedia page first
4. Check browser console (F12) for errors
