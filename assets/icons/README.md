# Extension Icons

This folder should contain the extension icons in the following sizes:

- `icon16.png` - 16x16 pixels (toolbar)
- `icon32.png` - 32x32 pixels (toolbar @2x)
- `icon48.png` - 48x48 pixels (extension management)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Creating Icons

To create icons for this extension:

1. **Design Theme**: Old-school academic style
   - Vintage book icon
   - Sepia/brown color palette (#8b7355, #d4a574)
   - Classic serif typography for "AI" text
   - Paper texture or leather-bound book aesthetic

2. **Recommended Tools**:
   - Figma, Adobe Illustrator, or Photoshop
   - Online icon generators
   - AI image generators with vintage style prompts

3. **Sample Prompt for AI Generation**:
   ```
   Create a browser extension icon for an AI learning tool.
   Style: vintage academic, old-school textbook, sepia tones.
   Elements: open book, graduation cap, or brain icon.
   Colors: warm browns (#8b7355), gold (#d4a574), cream (#f5f0e8).
   Simple, recognizable at small sizes, classic design.
   ```

4. **Quick Placeholder**:
   For testing, you can use any placeholder icons or generate simple colored squares with the text "AI" in a classic font.

## Temporary Solution

Until you create custom icons, you can:

1. Use online icon generators (e.g., favicon.io, realfavicongenerator.net)
2. Create simple text-based icons with the letters "AI"
3. Use free icon resources from:
   - Flaticon.com
   - Iconfinder.com
   - Icons8.com

Make sure any icons you use are:
- PNG format
- Transparent background
- Exact pixel dimensions (16, 32, 48, 128)
- Consistent visual style across all sizes
