🚀 Quick Start Guide

How to Use Learn with DeepMind

1

Get Your API Key

Visit Google AI Studio, create an API key, and paste it above.

2

Test & Save Your Settings

Click "Test Connection" to verify your key works, then click "Save Settings" below.

3

Navigate to Learning Content

Open any article, blog post, or documentation page you want to learn from.

4

Click the Floating Button

Look for the circular "AI" button in the bottom-right corner of the page and click it.

5

Process Your Content

In the side panel, click "Summarize Content" or any other processing option. Wait 20-60 seconds.

6

Create Visualizations

Go to the "Visualize" tab and click "Generate Visualization" to create mind maps.

7

Test Yourself

Use the "Quiz" tab to generate practice questions and test your understanding.

8

Review Your Library

Access all saved content in the "Library" tab for quick review before exams.

💡 Pro Tips

  • Start Simple: Try a Wikipedia article first to get familiar
  • Be Patient: AI processing takes 20-60 seconds - don't spam click!
  • Use All Features: Summaries + Mind Maps + Quizzes = Better retention
  • Export Regularly: Backup your library using the export button above
