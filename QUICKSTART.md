# Quick Start Guide - AI Learning Accelerator

Get up and running in 5 minutes!

## 1. Get Your API Key (2 minutes)

1. Visit https://makersuite.google.com/app/apikey
2. Sign in with Google
3. Click "Create API Key"
4. Copy the key

## 2. Install Extension (1 minute)

1. Open Chrome → `chrome://extensions/`
2. Enable "Developer mode" (top-right toggle)
3. Click "Load unpacked"
4. Select the `learnfasterwithai` folder
5. Done! Extension icon appears in toolbar

## 3. Configure (1 minute)

1. Click extension icon
2. Click "⚙ Settings"
3. Paste your Gemini API key
4. Click "Save Settings"

## 4. Start Learning! (1 minute)

### Try It Now:

1. **Open any article** - Try Wikipedia or a blog post
2. **Click the floating button** - Bottom-right corner (or click extension icon → "Analyze This Page")
3. **Wait for processing** - Side panel opens
4. **Click "Summarize Content"** - See AI magic in action!

### What to Try:

**Process Tab:**
- 📋 Summarize Content - Get key points
- 💡 Extract Key Concepts - See main ideas
- 🔍 Simplify Language - Easier explanations
- 🧩 Identify Patterns - Find learning frameworks

**Visualize Tab:**
- Generate mind maps
- Create flow diagrams
- Export visualizations

**Quiz Tab:**
- Generate practice questions
- Test your understanding

**Library Tab:**
- View saved materials
- Browse past summaries

## Common First-Time Tasks

### Summarize a Long Article
1. Open article
2. Click FAB button (floating)
3. Click "Summarize Content"
4. Wait 10-30 seconds
5. Read summary in result box

### Create a Mind Map
1. Analyze any learning content first
2. Go to "Visualize" tab
3. Click "Generate Visualization"
4. See mind map appear
5. Click "Export" to save

### Upload a Document
1. Click extension icon
2. Click "Upload Document"
3. Select .txt file (PDF support coming)
4. Process like any other content

## Tips for Best Results

✅ **DO:**
- Use on educational content (articles, docs, tutorials)
- Give it 20-60 seconds to process
- Try different processing types
- Save important summaries to library

❌ **AVOID:**
- Very short content (< 500 words)
- Pages with lots of ads/navigation
- Protected/paywall content
- Extremely technical PDFs initially

## Keyboard Shortcuts

- Open side panel: Click FAB button
- Copy result: Use copy button in results
- Switch tabs: Click tab navigation

## Troubleshooting (30 seconds)

**Nothing happens when I click the button?**
→ Refresh the page, try again

**"API key not configured" error?**
→ Go to Settings, add your Gemini API key

**Can't see the floating button?**
→ Click the extension icon in toolbar instead

**Content not extracting?**
→ Try a different page or upload a document
